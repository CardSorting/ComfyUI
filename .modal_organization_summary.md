## 🚀 Using the New Structure

### Deployment
```bash
# Option 1: Use wrapper (recommended)
./modal_deploy.sh

# Option 2: Direct command
modal deploy modal/apps/modal_app_fastapi.py
```

### Model Management
```bash
# Option 1: Use wrapper (recommended)
./modal_manage.sh list
./modal_manage.sh download-url "URL" checkpoints
./modal_manage.sh delete checkpoints model.safetensors

# Option 2: Direct commands
modal run modal/apps/modal_app_fastapi.py::list_models
modal run modal/apps/modal_app_fastapi.py::download_model --url "..." --category checkpoints
```

### Testing
```bash
python modal/tests/modal_test_endpoints.py YOUR_ENDPOINT_URL
```

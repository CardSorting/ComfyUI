EASIEST WAY (Interactive Wizard):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Just run this command and answer the questions:

    python modal_setup_wizard.py

The wizard will:
  ✓ Install everything you need
  ✓ Set up your Modal account
  ✓ Deploy ComfyUI for you
  ✓ Help you download models
  ✓ Test that everything works

Time: 10-15 minutes (mostly waiting for downloads)

ALTERNATIVE: Do It Yourself (5 Commands)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Install Modal:
   pip install modal

2. Login to Modal:
   modal setup

3. Deploy ComfyUI:
   modal deploy modal_app.py

4. Download models:
   modal run modal_app.py::download_models

5. Done! Your ComfyUI is running in the cloud!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHAT IS THIS?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This deploys ComfyUI to Modal.com - a cloud platform that:
  • Gives you GPU access (no expensive hardware needed!)
  • Scales automatically (1 user or 1000 users - it handles it)
  • Only charges when used ($0 when idle!)
  • Provides an API endpoint you can call from anywhere

Cost example: ~$0.005 per image (with A10G GPU)

Q: I'm completely new. What do I do?
A: Run: python modal_setup_wizard.py

Q: How much does this cost?
A: ~$0.005 per image. Free when idle. See START_HERE.md for details.

Q: Where do my models go?
A: They're stored in Modal's cloud storage. You don't need them locally!

Q: How do I add models?
A: The wizard can do it, or see MODAL_DOWNLOAD_MODELS_FROM_URL.md

Q: Can I change the GPU?
A: Yes! Edit modal_app.py or run the wizard again.

Q: How do I use my deployed ComfyUI?
A: Send HTTP requests to your endpoint URL. See START_HERE.md.
